One question, one evidence path

The system adapts its computation to the question instead of processing every modality for every video.

Motivation. Video questions need different evidence: ordering needs scene sequences, layout needs keyframe positions, movement needs tracks over time, “how many” needs de-duplicated instances, and speech or sound needs transcripts and audio tags. Running every model for every question spends GPU and API resources on evidence the question does not need.

Approach. GPT-4o mini assigns each question to exactly one category. Only the matching branch executes; the other four are not invoked. The resulting evidence is embedded into a per-video ChromaDB collection, retrieved with dense and lexical signals, and passed to a category-aware answer generator. Invalid classifier labels fall back to spatial.

Framework overview

Classification and answer generation always run. Exactly one evidence branch runs for each question.

Input ingestion

Load query/video pairs and resolve the source video.

Query routing

GPT-4o mini selects temporal, spatial, motion, counting, or audio.

Cache check

Reuse branch chunks already stored for this video and category.

One branch

Run only the specialized local and API tools needed by the query.

Embed & store

BGE encodes branch output into a persistent ChromaDB collection.

Hybrid retrieval

Dense search is filtered by category and re-ranked with BM25.

Answer generation

A category-specific GPT-4o mini instruction grounds the response.

Structured output

Save the answer, route, video, query, and optional ground truth.

Five ways to understand a video

Each branch creates text evidence designed for a distinct reasoning pattern.

Temporal

Trigger: ordering, sequence, and before/after timing.

Stack: PySceneDetect, ffmpeg, and GPT-4o-mini scene captioning.

Evidence: timestamped, ordered scene captions from representative mid-scene frames.

Spatial

Trigger: layout, position, or where something appears.

Stack: CLIP keyframe selection, K-Means, GPT-4o-mini layout captions, and Grounding DINO-tiny.

Evidence: keyframe descriptions and grounded object labels.

Spatio-temporal

Trigger: how something moved or changed position over time.

Stack: RT-DETR R50VD and a custom IoU/Hungarian tracker.

Evidence: per-track start position, end position, and time span.

Counting

Trigger: “how many” questions.

Stack: RT-DETR with the same tracker to de-duplicate repeated sightings.

Evidence: exact unique-instance counts with supporting frame metadata.

Audio

Trigger: speech, dialogue, or non-speech sound events.

Stack: Whisper large-v3-turbo and AST AudioSet tagging.

Evidence: timestamped transcript segments annotated with sound-event tags.
